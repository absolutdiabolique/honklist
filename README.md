# 🐦 Honk Demonlist

A difficulty-ranked leaderboard for [Honk](https://reddit.com/r/honk) levels, powered by stats scraped from **u/flappy-goose**'s bot comments.

## Setup

```bash
git clone https://github.com/YOUR_USERNAME/honk-demonlist
cd honk-demonlist
```

## Adding Levels

Edit `data/levels.txt` and add one Reddit post URL per line:

```
https://www.reddit.com/r/honk/comments/1s8z5m9/hes_beginning_to_believe/
https://www.reddit.com/r/honk/comments/XXXXXX/another_level/
# Lines starting with # are ignored
```

## Scraping Stats

Run the scraper to pull stats from each post's flappy-goose comment:

```bash
python scripts/scrape.py
```

This writes `data/stats.json`. Re-run whenever you add levels or want updated stats.

## GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages → Source → main branch / root**.
3. Your demonlist will be live at `https://YOUR_USERNAME.github.io/honk-demonlist/`.

> **Note:** The scraper must be run locally (or in a GitHub Action) and the resulting `data/stats.json` committed before the site will show data.

## File Structure

```
honk-demonlist/
├── index.html          ← Main leaderboard page
├── data/
│   ├── levels.txt      ← One Reddit URL per line
│   └── stats.json      ← Auto-generated by scrape.py
└── scripts/
    └── scrape.py       ← Scraper script
```

## Scraped Stats (per level)

| Field | Description |
|---|---|
| `title` | Reddit post title |
| `attempts` | Total attempts |
| `completions` | Total completions |
| `success_rate` | % success rate (used for ranking) |
| `fastest_time` | Fastest recorded completion time |
| `first_completion` | Username of first completer |

Levels are sorted **hardest first** (lowest success rate = rank #1).
